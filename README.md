# AI for Beginners & Seniors Website

A Next.js website for teaching AI to beginners and seniors.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The AI for Beginners page is available at [http://localhost:3000/ai-for-beginners](http://localhost:3000/ai-for-beginners).

## Project Structure

- `app/ai-for-beginners/page.tsx` - Main AI for Beginners page
- `app/layout.tsx` - Root layout with metadata
- `app/globals.css` - Global styles with Tailwind CSS
- `app/page.tsx` - Home page

## Technologies

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
